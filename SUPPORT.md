# Support

- Use [GitHub Discussions](https://github.com/jamescross91/solis-tools/discussions)
  for installation, configuration and usage questions.
- Use a structured [GitHub issue](https://github.com/jamescross91/solis-tools/issues/new/choose)
  for reproducible bugs or feature proposals.
- Use [private vulnerability reporting](https://github.com/jamescross91/solis-tools/security/advisories/new)
  for security concerns.

Include the Solis model, firmware or protocol code, operating system,
installation method and `solis-poll --version` output where relevant. Remove IP
addresses, network details and other sensitive information before posting logs.
